# Bank Customer Churn & Retention Analytics

## Executive Summary
This project analyzes a 10,000-record commercial banking dataset to uncover key demographic and financial drivers behind customer attrition. By integrating **Python**, **SQL**, and **Power BI**, this end-to-end analysis evaluates $185.59M in lost deposit risk and provides data-driven retention strategies.

## Key Insights
* **Overall Attrition:** 20.37% overall churn rate across 10,000 accounts.
* **Geographic Risk:** Germany exhibits a 32.44% churn rate, double that of France and Spain (~16.15%).
* **Account Balance Impact:** Accounts holding balances >$50k churn at 24.05%, compared to 14.25% for low-balance customers.
* **Engagement Level:** Inactive members churn at 26.85% vs. 14.27% for active accounts.
